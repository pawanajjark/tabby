# Chat workspace

Mode: Operate

Audience: roommates coordinating a shared home. Job: speak naturally, see the correct specialist act, and retrieve relevant household context without exposing raw personal chat. Primary action: send a message. Constraints: no emojis, no fabricated data, keyboard-first, responsive, existing SpacetimeDB contract.

## Direction contract

THESIS: Conversation is the operating system; reject the tabbed dashboard and expose tools only inside the dialogue that summons them.

OWN-WORLD: Midnight-blue command rail, cool white conversation field, crisp cobalt action color, and narrow color-coded specialist labels. Sans typography, firm one-pixel rules, restrained radii.

STORY: Ask once, watch intent route, review the grounded result, and continue with household memory intact.

FIRST VIEWPORT: Slim identity rail left, dominant chat transcript center, live household context right; composer anchors the center bottom and routed work expands inline.

FORM: Brief-pinned chat workspace, seed brief-pinned-chat-first. Signature interaction: the routing label changes before the relevant result card resolves.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
